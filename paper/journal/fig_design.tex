\caption{Design of the study. (a)~Left: four levels of one class hierarchy of the \Kfull{}
JetClass-II classes and what each merge removes. Every class holds only QCD jets, only decays into
quarks and gluons, or only decays with leptons. Right: the controls. The random partitions keep the
group sizes of the \Kcoarse-class level but assign the decays to the groups at random; they have
many flavor boundaries and no topological order. The flavor-controlled partitions fix where the
flavor boundaries lie. Two further variants add a mass-regression output or remove the particle-type
and track-displacement inputs. Figure~\ref{fig:labelsets} shows the classes of selected decays in
each label set. (b)~Models with the same seed see the same training jets in the same order from the
same initial weights, so two models of one seed differ only in their labels and output layer. Every
model is evaluated with probes on its frozen features and with full fine-tuning on the same tasks.}
\label{fig:design}

# RESULTS — running ledger

Every training/eval run appends a provenance block here (auto-generated by
`scripts/collect_provenance.py` → also writes `<run-dir>/run_provenance.json`).
This is the single accessible record of *what was run, on what, at what cost, with
what result* — for the paper's reproducibility + compute-reporting requirements.

## Reproducibility policy
- **Seeds**: weaver 0.4.17 exposes no `--seed` and never seeds torch, so runs
  before 2026-07-13 are **UNSEEDED** (entropy weight-init + data order). From E1's
  seeded rerun onward, all runs go through `experiments/E1/seed_weaver.py`, which
  seeds python/numpy/torch/cuda in-process before weaver builds the model.
- **Determinism level**: seed-only (no `use_deterministic_algorithms`). A run is
  **labeled and reproducible on the same GPU model**; cross-GPU is statistical, not
  bit-identical (different CUDA kernels/reduction order) — inherent to the
  heterogeneous NRP cluster. State this caveat in the paper.
- **Statistics**: multi-seed spread + paired bootstrap on shared test sets (per the
  master plan). N seeds = N independent labeled runs.

## Reported per run
seed · git commit · image digest · weaver/torch/CUDA versions · GPU model+count+node ·
params · wall-clock + per-epoch + GPU-hours · FLOPs/jet + total training FLOPs ·
energy (kWh / CO₂e est) · full hyperparameters + data-config · per-epoch val curve ·
best epoch · eval metrics.

# E1 — Pipeline validation & preprocessing tax

**Design**: same Sophon architecture (ParT backbone 8+2 blocks + Sophon head,
2.21 M params), same recipe (Ranger + flat+decay, 50 ep, batch 512, lr 1e-3),
trained from scratch on JetClass-1 twice — **Arm P** (ParT preprocessing) vs
**Arm S** (Sophon preprocessing: pT-rescale + flat (pT,mSD) reweighting). Gate =
Arm P macro AUC within 0.002 of published ParT 0.9877. Tax = Arm P − Arm S
(paired bootstrap on shared test_20M).

|---|---|---|---|

Evaluated on full 20 M test set (2 M/class). Verdict computed by combining the 10
per-class `pred_*.root` files. **Caveat**: Arm P here is the Sophon architecture (ParT
backbone + Sophon head), not a bit-identical ParT clone; and this run is UNSEEDED —
published 0.9877 is a **reference line**, not a same-network same-seed comparison.
